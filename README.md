# JobConnect Pro — Complete MERN Job Portal

A production-style MERN fresher portfolio project with Candidate, Recruiter and Admin flows.

## Requirements
- Node.js 18+
- MongoDB local or MongoDB Atlas

## Run
1. Open this folder in VS Code.
2. Copy `server/.env.example` to `server/.env`.
3. Set your MongoDB connection string.
4. Run from root:
   npm install
   npm run install-all
   npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000

## Demo
Register as Candidate or Recruiter. Admin can be created by changing a user's role to `admin` in MongoDB.

## Main features
- JWT cookie authentication
- Candidate / Recruiter / Admin roles
- Job CRUD
- Advanced search and filters
- Saved jobs
- Applications and status workflow
- Candidate profile and resume URL
- Recruiter dashboard
- Admin dashboard
- Notifications
- Pagination
- MongoDB indexes
- Protected React routes
- Responsive modern UI
